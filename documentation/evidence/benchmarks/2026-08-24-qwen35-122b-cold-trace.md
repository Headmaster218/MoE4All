# Qwen3.5-122B 冷启动到 2K 的有序追踪

模型 `Qwen3.5-122B-A10B-APEX-I-Quality.gguf` 的路由专家载荷为 72.36 GB，超过本次 RAM 预算。RX 7900 XTX 上使用 20 GiB 显存预算、51 GiB 有界 RAM（界面显示 54.76 GB）、Q8_0 K/V、4096 上下文；新进程接收 70 个 prompt token 并 Decode 2048 token。此处的 11.2 tok/s 是冷进程长运行结果，不应与后续 tg256、热缓存的 23.2 tok/s 混为一谈。

阶段资料将 `7eb9f0d` 标为有序追踪实现提交，但正常文本输出依赖后续 `1accc8c` 的 recurrent-state 重置修复。原始运行二进制的精确提交未独立留存，所以不把 `7eb9f0d` 误写成这次正常 2K 运行的 `measured_commit`。

## 顺序与命中

| 阶段 | Pager 调用 | 专家块访问 | GPU hit |
|---|---:|---:|---:|
| 启动预热 | 96 | 2304 | 11.849% |
| 请求 Prefill 路由 | 48 | 79488 | 79.506% |
| Decode | 98304 | 2359296 | 69.573% |
| 总计 | 98448 | 2441088 | 69.842% |

`2048 * 48 层 * 8 专家 * 3 角色 = 2,359,296`，追踪没有调用编号倒退或访问序列中断。Decode 的 GPU hit 从 token 0-127 的 72.125%，经 128-511 的 71.248%、512-1023 的 70.309%、1024-1535 的 67.428%，到 1536-2047 的 69.088%；它没有随着预热单调升到 90%。Gate/Up/Down 的命中率分别为 69.840%/69.842%/69.844%，不支持固定角色配额。

请求共出现 734155 次 GPU miss，其中 709162 次在 RAM 命中，RAM 条件 hit 为 96.596%；SSD 读取 24993 个块、约 50.227 GB，占请求访问量 1.025%，折合每个生成 token 12.20 块（包含一次请求 Prefill 路由）。按池的访问数为 1423968/508560/508560，GPU hit 为 74.711%/61.683%/64.367%；按层 hit 约在 41.2%-88.5% 之间。这些差异解释了为何有限的 Host DMA import 额度必须按池覆盖率分配，而不能让首个池先耗尽。

## 改进与正确性

长运行曾连续输出 `!`，原因是清空 KV 后未同步重置混合模型的 recurrent state；`1accc8c` 修复后才取得正常输出和上述追踪。共享专家融合的 tg256 ABBA 在 15.58 GB 已映射 ReBAR、54.76 GB RAM 下，从 17.0/17.3（均值 17.15）提至 19.2/19.2（均值 19.20）tok/s，35B 防回归对照从 85.7/86.5 到 90.0/90.6。Host DMA 随后从 CPU 路径 19.2 提至先到先得 import 的 22.4，再由 `497460a` 的按比例 import 达到 23.2 tok/s（三次为 22.7-23.5）；最终 GPU 专家区 13.97 GiB，45.00 GiB RAM 中导入 28.99 GiB，三池覆盖率 62.6%/67.7%/64.9%。这两组 tg256 不是冷 2K 追踪的复测。

旧阶段总结将热 tg256 的 19.2→23.2 写作进一步提升约 20.8%；这是从共享专家融合阶段到最终 Host DMA 阶段的合计变化，不能归因于单个补丁，也不能与上面的冷 2K 运行交叉计算。旧总结还把 shared-fusion A/B 写作约 +11.5%～12.9%、35B guard 写作约 +4.7%～5.7%；按本页保留的两对原始样本逐对计算，范围分别约为 +11.0%～12.9% 和 +4.7%～5.0%，因此不沿用旧百分比上界。

追踪可用于按真实访问顺序回放各尺寸池 LRU、inclusive RAM shadow 和 SSD miss；模拟不能证明 DMA/计算重叠，也不能假设改变量化后路由不变。对应的传输与调度量级见[MoE 微基准](2026-08-25-moe-pager-microbench.md)，当前内存机制见[资源生命周期](../../architecture/memory/runtime-resource-lifecycle.md)。
