# 0.10.0 发布前性能与稳定性矩阵

## 基线和口径

本记录提炼 2026-10-09 的 release validation REPORT/summary，不是本次重跑。测试提交 `53afa86f3215aa0d1259bafbc0b069152da844a5`，EXE SHA256 `8242EE47874FB7E62105DBAA1315E60027C99C6097CDAFC35AA90B8D171D8D04`。候选 ZIP SHA256 `C05C8A0AB8FAF31A55DA43FF4F1DB59031869EBC434A12CD4CDBF1B9A80E298E`，不是 final tag 发布 ZIP 的校验值。

Windows、RX 7900 XTX、Ryzen 5 5600X、64 GiB RAM，portable x86_64/static CRT；Qwen3.8 Flash-Next AD 4.27bpw Q4_K_M-M64 与 Qwen3.6-35B-A3B APEX-I-Balanced。每个 cell 新启动服务，配置 3 KV slots，实际活跃 1/2/3；ctx=163840、aggressive、Q8 K/V、MTP off、CPU miss off。匹配 Vision mmproj 与 Qwen3-Embedding-0.6B Q8_0/idle=60 已配置，主矩阵请求为文本；sampling/thinking 为各模型默认。

每 cell 冷 Prefill 后跑三轮 Decode、每 lane 768 tokens，第 2/3 轮复用缓存。P 是 group 首次进度至最后提示完成的 aggregate，排除最多约 1 秒初始等待。全程 D 与所有 lane 同时 Decode 的共同窗口 D 分开。前/中/后按 wall time 三等分；P peak 为 chunk 插值显示峰值，D peak 为 1.5 秒 interval 最大值，都不是 kernel 瞬时吞吐。以下所有速度为 tok/s，D 为 aggregate 而非每 lane。

## 有限稳定性与资源

12 cells、36 rounds、72 responses、55296 generated tokens，报告为 0 failed、0 cache miss；12 次安全排空退出 143，均有 GPU released 标记。这是有限矩阵，**不是 24/48 小时 soak**，也不是对所有采样/辅助请求的证明。

Flash-Next arena 约 16.67 GiB，RAM expert payload 47.17 GiB，Host DMA import 约 31.02/47.17 GiB，其余 tail 使用 fallback；Balanced arena 约 19.71 GiB、完整 host payload 约 21.95 GiB。Flash-Next Windows commit headroom 最低约 0.3..0.7 GiB、working set 峰值约 47.5..47.9 GiB；Balanced 分别约 1.9..2.6 GiB 与 22.2..22.3 GiB。这些不能单独证明没有换页，更不能推算内存泄漏。实际 ubatch 4096，修复后的 ring 通常 3..4 lanes，不能与 KV slots 混为一谈。

## 辅助服务 overlap 和历史失败

同一30K prompt，每模式两轮1024tokens；每轮Embedding发12次、每次完成后间隔1秒，或发4张新的256×256图片、每次完成后间隔3秒。combined模式复用Vision模式见过的图片，CPU image-result cache可能生效；不等于完全冷的新图组合。旧安装和source-HEAD对照是既有generic binary，不是同toolchain重建，不能把所有P差额归给单一修复。
