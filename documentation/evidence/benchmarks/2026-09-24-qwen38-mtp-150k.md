# Qwen3.8 MTP 与普通 Decode：150K 输入

## 溯源信息

- 来源：checkpoint `ee492e2e7e2c177e4cf6700ca64ac72a412988f4` 中的 `README.md` 汇总表；该摘要由 `14505d5a`（2026-09-24）提交写入。此日期是文档记录日期，不等同于运行日期。
- 原始运行 ID、完整命令、运行 commit、binary hash 和逐次结果未随该汇总保存；本页保留已发布数字，不将它们标成可复现的 `measured` 记录。
- 硬件：AMD Radeon RX 7900 XTX 24 GiB、Ryzen 5 5600X、64 GiB DDR4、Windows 11。
- 模型：Qwen3.8-Flash-Next-AD-4.27bpw-Q4_K_M-M64；MTP 使用匹配的 `mtp-Qwen3.8-Flash-Next-shared-Q4_K_M.gguf`。
- 配置：自动激进策略、Q8 K/V、greedy、关闭 thinking、单路生成；context capacity 为 163,840。
- 详细 prompt、输出 token 数、预热和重复次数：汇总源未记录。

## 结果

速度单位为 tok/s。中段为生成 token 的 25%–62.5%，后段为 62.5%–100%；Alpha 为 MTP 草稿接受率。

| 负载 | 模式 | 实际 prompt tokens | Prefill | Decode 全程 | 中段 | 后段 | Alpha |
|---|---|---:|---:|---:|---:|---:|---:|
| 简单问题 | MTP | 149,849 | 769 | 48.1 | 49.2 | 46.8 | 0.979 |
| 复杂问题 | MTP | 149,857 | 766 | 33.4 | 35.5 | 34.3 | 0.642 |
| 简单问题 | 无 MTP | 149,849 | 888 | 32.4 | 32.0 | 32.9 | — |
| 复杂问题 | 无 MTP | 149,857 | 889 | 30.8 | 31.4 | 31.2 | — |

从 20K 增至 150K，四种组合的全程 Decode 分别下降 20.1%、16.3%、14.1% 和 12.0%；Prefill 分别下降 17.8%、18.2%、14.2% 和 14.0%。这些百分比沿用 README 的同 prompt 类别比较。

## 解读限制

复杂问题下 MTP 全程 Decode 比无 MTP 高约 8.4%，简单问题高约 48.5%；收益明显依赖接受率。README 未保留输出等价性、逐轮重复和原始日志，不能据此推断置信区间或单独归因于某项 commit。20K 测试条件与原因分析见[20K benchmark](2026-09-24-qwen38-mtp-20k.md)。
