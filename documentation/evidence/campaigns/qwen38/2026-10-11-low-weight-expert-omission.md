# 低权重专家跳过：真实输出记录与局部误差

## 结论与范围

本实验回答：每轮 Router 动态选出的低权重专家，删除后是否可能显著改变本层 hidden？

**可能。权重是有效信号，但不能单独给出误差上限。** 在本次记录中，单个权重低于 10% 的专家被删除后，四路 hidden 合并相对 L2 误差最高为 **9.34%**。选择 low2 比 low3 能更好地排除本次观测到的尾部异常；重归一化大多数时候反而增大误差。

这里的证据分为两部分：完整模型实际生成并记录专家向量属于 `measured`；对这些向量做固定输入删除、重归一化和策略筛选属于 `simulation`。生成过程中所有专家都正常计算，**没有实际启用跳过，也没有测得跳过策略的速度或最终回答质量**。

该实验使用普通分页参考路径，不是另一个工作树中的 GPU 自主继续 Decode。不能用这里的 miss 分布或受采集干扰的速度估算该优化路径的收益。

未实现的分档与运行时约束见[策略提案](../../../roadmap/low-weight-expert-omission.md)。本 PR 只发布提炼结果与图表，不改推理行为。

## 误差定义

令原 routed 混合为 `R = Σ w_i e_i`，shared 为 `S`；完整 FFN 为 `B = R + S`。删除集合为 `D`，`U = Σ(i∈D) w_i e_i`，幸存混合为 `V`。

- 不重归一化：新 FFN 为 `B - U`，扰动 `ΔB = U`。
- 重归一化：`a = Σw_i / Σ(i∉D)w_i`，新 FFN 为 `S + aV`，扰动 `ΔB = U - (a - 1)V`。保持原 routed 总权重，不缩放 shared。
- 四路 HC：`h_s = residual_s + 2 sigmoid(g_s / 4) B`。每路扰动为对应 HC 系数乘 `ΔB`。
- 合并 hidden 误差：拼接四路后的 `||Δh||₂ / ||h||₂`；FFN 误差为 `||ΔB||₂ / ||B||₂`；最差单路为四路相对误差的最大值。

联合删除按**向量相加**计算，不把单个误差范数相加。重归一化的全部 routed 删除、零分母相对误差以及无触发样本均为未定义，不当作零误差。

下文 P50/P95/P99/max 均是触发样本的描述统计，默认不重归一化。不是逐步滚动后的误差，不是 logits 偏差、任务准确率或最终文本质量；P95 也不是安全上界。

## 权重与实际影响

平均权重从最高至最低依次为：20.08%、14.42%、11.78%、10.08%、8.91%、8.05%、7.39%、6.83%、6.40%、6.05%。最后四名合计约 26.68%，并非可忽略的尾部。选中专家权重和约为 1；没有权重低于 1% 的样本，低于 2% 仅 3 次。

| 单专家删除条件 | 专家记录数 | 合并 hidden P50 | P95 | 最大值 |
| --- | ---: | ---: | ---: | ---: |
| 权重 <5% | 901 | 1.04% | 2.15% | 4.44% |
| 权重 <10% | 11,964 | 2.00% | 4.44% | 9.34% |

几个可追溯反例：

| 层 / capture | 专家 | 权重 | 原专家输出范数 | 合并 hidden 删除误差 |
| --- | ---: | ---: | ---: | ---: |
| L0 / 832 | 359 | 7.75% | 4.3847 | **9.34%** |
| L0 / 832 | 401 | 15.01% | 0.9338 | 3.85% |
| L44 / 9280 | 452 | 8.03% | 14.1247 | 4.83% |

同一个 L0 样本里，低权重专家的影响约为高权重专家的 2.42 倍。L44 的该专家删除造成 FFN 误差 51.24%、合并 hidden 4.83%、最差单路 **15.25%**：残差分母和 HC 各路系数让几个指标不能互换。

选中专家的误差取决于 `权重 × 输出向量`、向量方向/抵消、残差尺度和 HC 注入。实际输出范数是计算后的量，**不能免费用于提前跳过判定**。用历史幅度或输入代理预测仍需独立验证。

## Miss 与 low 的关系

`lowN` 指本轮选中 10 个 routed 专家里按实际权重排序的最低 N 名，使用 slot 顺序作为同权重的确定性 tie-break；不是模型中固定的几个专家。

记录中有 1,241 次 miss，779 层至少一个 miss。恰好 1 miss 为 494 层，2 miss 为 177 层；其余 108 层有至少 3 个 miss。以下概率先不加权重阈值：

| 集合 | 单 miss 在其中 / 494 | 双 miss 至少一个在其中 / 177 | 双 miss 全部在其中 / 177 |
| --- | ---: | ---: | ---: |
| low1 | 20.85% | 38.42% | 0% |
| low2 | 38.06% | 62.15% | 10.73% |
| low3 | 52.63% | 77.40% | 24.29% |

`P(在低权重集合 | miss)` 与 `P(miss | 在低权重集合)` 分别统计；完整分母和条件见下方 JSON。只覆盖双 miss 中的一个，不等于本层不再需要确定性上传。

## 108 组策略筛选

组合包括：miss 恰好 1、恰好 2、或任一种；low1/2/3；严格小于 3/5/7/9%；三种删除语义：

1. `partial_each`：只删满足排名与单项阈值的 miss，其他 miss 正常算。
2. `all_each`：所有 miss 均在 lowN，且各自权重低于阈值，才全部删。
3. `all_total`：所有 miss 均在 lowN，且总 miss 权重低于阈值，才全部删。

每组均有原权重和重归一化对照。对 1/2 miss 的任意删除子集复用单专家或完整联合 miss 的精确向量结果，不需要重跑 GPU。

## 重归一化

总 miss 权重 <10% 的原始策略触发 432 层；重归一化让其中 426 层局部 hidden 误差增加、6 层减小。

在低权重分档候选中，1/2 miss、low2、每个 <7% 共 156 层：重归一化改善 2 层、恶化 154 层；P95 从 2.76% 增至 3.13%，最大从 4.68% 增至 6.24%。因此初期候选保留原权重，重归一化作为独立实验变量，不默认开启。

某些最大值降低并不意味着整体改善。例如 low3、<9% 的最大值从 9.34% 降至 8.49%，但 P95 从 3.08% 增至 3.98%，300 层中 295 层变差。

## 校验与尚未覆盖

- 离线重建与组合筛选单元测试 20/20 通过；覆盖同权重排序、严格阈值、hit 不删、1/2 miss、单项/总权重区别、联合向量删除、归一化和无样本。
- 从原始向量复核了一个双 miss 联合删除样本，原权重与重归一化结果和复用结果一致。
- 图表经浏览器检查：旋转/缩放、条件切换、明暗主题、桌面/手机非空 canvas 与无水平溢出；双图共用刻度，并同步视角。
- **未覆盖**：真正跳过后的长程 hidden/Router/GDN 状态演化，logits/KL、代码正确率、长推理/工具成功率、其他 Prompt/模型/量化/设备、多路生成，以及 GPU 自主继续路径的速度与 cache 反馈。

下一步应先验证少量分档候选的真实质量和净耗时，再决定是否提供用户入口；不能把“覆盖了多少 miss 层”直接写成“加速了多少”。
