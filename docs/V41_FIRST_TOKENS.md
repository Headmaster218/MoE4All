## Round 169：一个新的定量判据（不依赖参考引擎的输入对齐）

### 极端简化的对照：只改一个 token

```
Hi: [0, 128803, 23166, 128804, 128821]
Ho: [0, 128803, 45038, 128804, 128821]      ← 只有这一个 token 不同
```

**参考引擎：**

| 输入 | top5 |
|---|---|
| Hi | **2581:91.60%**, 671:4.68%, 2337:1.11% |
| Ho | **2581:81.77%**, 671:8.90%, 42:1.93% |

**moe4all：**

| 输入 | top5 |
|---|---|
| Hi | **2619:6.31%**, 201:4.71%, 1492:3.18% |
| Ho | **2619:6.06%**, 201:6.03%, 294:5.76% |
| Hi there | **2619:7.74%**, 29:6.42%, 666:4.33% |

### 两个结论

**① 「对输入不敏感」是模型自身行为，不是 bug。**
参考引擎同样 top-1 不变（2581 → 2581），只是概率从 91.6% 降到 81.8%。
（我一度把这个当成 moe4all 的病征，对照后自我否定了。）

**② 真正的差异是置信度差 15 倍。**

| | top-1 概率 | 峰值 logit |
|---|---|---|
| 参考引擎 | **91.6% / 81.8%** | max=14.98 |
| moe4all | **6.3% / 6.1%** | max=14.05 |

**峰值绝对值几乎一样（14.98 vs 14.05），但 top-1 概率差 15 倍。**

**⇒ 这说明：峰值的绝对高度不是关键问题；真正的问题是第一名与后续名次之间的差距不够大，整个分布被抹平了。**

### 这个判据的价值

**它不需要参考引擎、不需要输入对齐、不需要逐层 dump。**
只要看 top-1 概率，就能判断「分布是不是被抹平」，而这正是信息没传到的直接表现。

**形成尖锐偏好需要表示里有足够的方向性；分布平坦说明表示失去了方向。**

### 下一步（比逐层 trace 更省事）

**先验证「抹平」是否与某个子系统相关。** 分别观察三个配置下 top-1 概率的变化：
- `INFR_ENGRAM_ZERO=1`（Hi 上已测：20.8%，比 6.3% 高 3 倍，但参考是 91.6%）
- `INFR_DSV41_BATCHED_PREFILL=0`（逐 token 路径）
- `INFR_NO_GATED_RMSNORM=1`

其中 engram 零注入把 6.3% 抬到 20.8% 是最有信息量的：**说明 engram 注入正在抹平分布。**
