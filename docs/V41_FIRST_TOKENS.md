## Round 184：engram 只是其中一个污染源，去掉它仍然错

### 关键读数

```
ENGRAM_ZERO: 51119:28.17%, 16:28.06%, 201:4.44%, 671:3.43%, 344:3.11%
参考:        生成 271, 5, 223, 19, 16, 10793
```

**两侧唯一的交集是 `16`。**

**⇒ 即使把 engram 的贡献完全置零，输出仍然不是参考的结果。**

**⇒ engram 是**其中一个**问题，不是全部。残差流里还有独立的缺陷。**

### 一个值得注意的信号

`51119:28.17%` 与 `16:28.06%` **几乎完全并列**（差 0.11 个百分点）。

这种"两个候选几乎并列"的形态，在分类器故障里通常对应**某个决定性特征被取反**：
本该强化 A 的那一维变成了强化 B。

**但这只是形态观察，不是证据。** 要把"取反"变成结论，需要看到 `51119` 和 `16` 的 embedding
或最终 hidden 在这两者上的投影 —— 又是需要中间张量的地方。
