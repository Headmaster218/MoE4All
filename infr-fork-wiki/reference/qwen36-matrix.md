# Qwen3.6-35B 阶段性能矩阵

[首页](../README.md) / [Reference](README.md) / Qwen 35B matrix

## 条件

- Commit：`637f23f`（async Prefill layer ring）。
- 模型：Qwen3.6-35B-A3B APEX-I Balanced。
- GPU：RX 7900 XTX / Vulkan0。
- Depth：0 / 32K / 64K / 128K / 250K。
- Expert cache：4 / 6 / 8 / 10 / 12 / 14 GiB（旧参数口径）。
- KV：Q8_0、F16。
- Prefill 4096 tokens，3 reps；Decode 1000 tokens，1 rep。
- ubatch 4096，submit unlimited；每项独立进程并保留正常 warmup。
- 单位：tokens/s；`—` 表示 VRAM guard 拒绝，不是驱动崩溃。

120 个组合中 107 成功、13 被 guard 安全拒绝，无 TDR/device reset。

## 当时配置结论

若目标是 200K～250K 对话，旧参数体系推荐 Q8 KV + 10G Expert cache：250K Prefill
476.3、Decode 43.7；F16 可安全的 8G 是 431.5 / 32.5。之后 total-budget/elastic arena
重构改变了用户参数口径，但“Q8 节省 KV 并把容量还给 Experts”的结论保持。
